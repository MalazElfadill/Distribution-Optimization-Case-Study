# Distribution Route Optimization Case Study

## Project Overview
I conducted a full data analysis of a **distribution network** for a food products company in Riyadh.  
The main goal was to improve fleet productivity and resource allocation by redesigning the visit model applied to retail stores.

---

## Business Challenge
Although the stores were segmented by purchasing power (A, B, C), all of them were visited **weekly**, regardless of demand or order frequency.  
This created several operational challenges:

- **Equal effort for unequal value** – all stores received the same visit frequency despite different sales levels.  
- **Effort not tied to demand** – delivery vans often visited stores even when no sales were expected.  
- **Low return on effort (ROE)** – only ~28 % of visits resulted in sales.

---

## Smart Visit Frequency Model
A new model was designed where visit frequency depends on **store value and buying behavior** instead of a single fixed schedule:

| Store Category | New Frequency | Rationale |
|----------------|----------------|------------|
| **A (High‑Value)** | Weekly | Highest ROI — keep regular visits |
| **B‑High** | Every 2 weeks | Moderate value — balanced coverage |
| **B‑Low** | Monthly | Lower priority segment |
| **C (Small Stores)** | Monthly | Visits only when sales patterns improve |

---

## Expected Impact
- Reduce unproductive visits by ~1 700 visits per year  
- Improve sales productivity from **27.9 % → ~ 39.3 %**  
- Achieve improvement **without adding vehicles or staff**
